# Happy Boyfriend's Day – React site

## Run
```
npm install
npm run dev        # open the URL on laptop; on phone use the Network URL
npm run build      # production build in /dist (upload to Netlify/Vercel/GitHub Pages)
```

## Flow
Landing → CONTINUE → "Please accept the gift" → YES = Choose Your Gifts / NO = "Why did you click no!" → TRY AGAIN.
Choose screen: envelope = letter, tulips = "i have the most handsome bf<3", gift box = vinyl + card + music.
